# CharacterKernel

CharacterKernel is a procedural, modular character-authoring foundation for building reusable 3D characters while preserving editable source data.

The project focuses on stable character topology, semantic regions, body parameters, rig compatibility, surface-relative attachments, modular hair and garments, deterministic validation, and fresh-process re-editability.

> Repository bootstrap in progress. Durable architecture, schemas, validation contracts, and Codex-facing authoring guidance are being introduced through a review branch.
